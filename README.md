# Controle 3D Valhalla — versões do aplicativo

Aplicativo para Windows e Android: peças prontas, filamentos, vendas, compras, contas e eventos.

[Baixar a versão mais recente](https://github.com/GregoryPina/controle-3d-releases/releases/latest) · [Privacidade](PRIVACIDADE.md)

## Instalação e atualização

- Windows: extraia todo o ZIP em uma pasta e abra `controle_3d.exe`.
- Android: instale o APK sobre a versão anterior, sem desinstalar ou limpar dados.
- O menu **Atualizações** consulta este repositório e verifica tamanho e SHA-256 antes de instalar. O Android exige a confirmação do sistema.
- Se uma versão antiga informar que a atualização exige assistência, use o pacote oficial da release e siga seu LEIA-ME.

## Uma planilha privada por loja

Entre com Google e escolha a planilha já preparada para o Controle 3D. Planilhas autorizadas anteriormente aparecem na lista. Para outra planilha, use o seletor oficial do Google. A permissão é limitada aos arquivos escolhidos para o aplicativo.

Compartilhe a planilha com os participantes como editores pelo Google Drive. Cada participante entra com sua própria conta. Lojas diferentes devem usar planilhas diferentes. Não publique suas planilhas nem compartilhe senhas.

Na versão 0.6.0, a loja fica salva no aparelho e os dados são consultados periodicamente enquanto o app está aberto. Gravações precisam de internet. Falhas e conflitos são mostrados para conferência; registros rejeitados permanecem no histórico, sem afetar os totais. Atualize todos os aparelhos da mesma loja antes de usar as novas correções compartilhadas.

## Catálogo com fotos e categorias

A partir da versão 0.7.0, abra **Peças prontas → Pasta de fotos**, informe o link da pasta da loja e confirme no seletor Google. A configuração fica na planilha, sem pasta fixa no aplicativo. Compartilhe a pasta com os participantes como editores. Cada conta pode precisar autorizar as fotos individuais pelo botão **Autorizar foto**.

Use **Foto** no cartão do produto e preencha **Categoria** em **Editar**. O catálogo permite escolher o produto ao vender. As imagens permanecem privadas no Drive; a planilha guarda apenas referências. Consulte o LEIA-ME da release para formatos, limites e instruções.

## Conteúdo deste repositório

Este é o canal de distribuição, não o repositório do código-fonte. Os arquivos “Source code” gerados automaticamente pelo GitHub contêm a documentação daqui. Não há registros de estoque, vendas, contas, planilhas particulares ou credenciais de usuários neste repositório.

Cada release oferece os pacotes e o manifesto `update.json`. Não é necessário login GitHub no aplicativo.
