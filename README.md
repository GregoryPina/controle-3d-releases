# Controle 3D — versões do aplicativo

Canal de distribuição do Controle 3D para Android e Windows.

## Download

[Baixar a versão mais recente](https://github.com/GregoryPina/controle-3d-releases/releases/latest).

- Windows: extraia todo o ZIP e abra `controle_3d.exe`.
- Android: instale o APK sobre a versão anterior, sem desinstalar.

A versão 0.2.0 inclui **Atualizações** no menu. Instale-a uma vez para que as próximas versões possam ser baixadas pelo próprio aplicativo. No Android, a instalação ainda depende da confirmação do sistema.

## Dados

Aplicativo pessoal em demonstração, com dados locais. A conexão Google Planilhas ainda não está disponível. Este repositório não contém registros de estoque, vendas, contas, credenciais ou o código-fonte do aplicativo. Os arquivos “Source code” gerados automaticamente pelo GitHub contêm somente a documentação deste repositório.

## Atualizações

Cada versão distribui APK Android, ZIP Windows e `update.json` com versão, compatibilidade e hashes SHA-256. O aplicativo verifica os arquivos e faz uma cópia dos dados antes de iniciar a instalação. No Windows, o instalador mantém backup dos arquivos substituídos e tenta restaurá-los se houver falha de cópia. Não desinstale o aplicativo Android para atualizar.

O canal é público e o aplicativo não guarda credenciais GitHub. Baixe apenas os arquivos publicados neste repositório.
