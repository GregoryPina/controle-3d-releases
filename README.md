# Controle 3D — versões do aplicativo

Canal de distribuição do Controle 3D para Android e Windows.

Os instaladores ficam em [Releases](https://github.com/GregoryPina/controle-3d-releases/releases). O aplicativo consulta este repositório quando você solicita uma atualização.

Este repositório não contém dados de estoque, vendas, contas, credenciais ou o código-fonte privado do aplicativo.

## Situação atual

Aplicativo pessoal em demonstração, com dados locais. A conexão Google Planilhas ainda não está disponível. A primeira versão com atualizador está em preparação.

## Atualizações

Cada versão publicará um APK Android, um ZIP Windows e um manifesto `update.json` com número da versão, compatibilidade e hashes SHA-256. No Android, a instalação depende da confirmação do sistema. No Windows, o atualizador fecha o aplicativo, mantém os dados separados e reabre após a troca de arquivos.

Baixe apenas os arquivos das versões deste repositório.
